What is this project?

An AI-powered student attention detection system for a Class 10 Science Fair. It uses a laptop's built-in webcam and Python's MediaPipe library to track 468 facial landmarks in real time, computing an attention score every frame.

MediaPipe Face Mesh

Google's MediaPipe tracks 468 precise 3D points on the face — eyes, mouth, nose, jawline, and irises. Running at ~15 fps, it enables detection of blinks, yawns, head turns, gaze direction, and drowsiness without any cloud or GPU.

Eye Aspect Ratio (EAR) — Blink Detection

The EAR formula measures how open each eye is using 6 landmark points. When EAR drops below 0.22 for 2+ frames, a blink is counted. When it stays low for 3+ seconds, drowsiness is detected.

EAR = (|p2−p6| + |p3−p5|) / (2 × |p1−p4|)

Threshold: EAR < 0.22 → eye closed · 3 s sustained → drowsy

Mouth Aspect Ratio (MAR) — Yawn Detection

Similar to EAR, the MAR measures mouth openness using 8 landmark points. A MAR above 0.60 indicates a yawn.

MAR = (top + bottom) / (2 × horizontal_width)

Threshold: MAR > 0.60 → yawn detected

Head Pose — Distraction Detection

The nose-tip landmark (#1) is tracked relative to the frame centre. Horizontal deviation beyond ±25° is classified as a head turn / distraction event.

Yaw = (nose_x − 0.5) × 180°

Iris Gaze Tracking

Using landmarks #468 (left iris) and #473 (right iris), the iris centre position relative to the eye boundary is computed. An offset >30% of eye width means the student is looking away from the screen. A downward offset >28% suggests looking at a phone or desk.

gaze_x = (iris_x − eye_centre_x) / eye_width

Attention Score Formula

A rolling 30-frame (2 s) window averages penalty-based scores. Each event subtracts from 100:

Drowsiness → −35 pts
Head turn → −20 pts
Yawn → −15 pts
Gaze away → −10 pts
Bad posture → −8 pts

Final score = rolling mean of last 30 frame scores.
